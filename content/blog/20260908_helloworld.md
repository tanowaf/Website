This is the first project status update. If you can read this, it means the publishing pipeline works correctly.

For the technically inclined:

this website's pages are built using a Static Site Generator: [Zola](https://www.getzola.org/);

the html styling and page layout come from the [DevLab](https://codeberg.org/RiPetitor/devlab-theme) theme for Zola;

the content is written in Markdown format, stored in a [Git repository on GitHub](https://www.github.com/tanowaf/Website);

the website itself is hosted on GitHub Pages;

a [GitHub Actions workflow](https://github.com/tanowaf/Website/.github/workflows/deploy.yaml) is used to build and
deploy the website whenever an update to the `main` Git branch is pushed to GitHub.
